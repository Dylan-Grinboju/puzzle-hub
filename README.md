# Puzzle Hub

A dashboard of daily word, geography, logic and trivia guessing games, with a random-pick page.

**Live:** https://dylan-grinboju.github.io/puzzle-hub/

- Click a game to open it; it's marked as played for today (resets daily).
- Favorites, search, category filters, hide-played.
- 🎲 Random picks an unplayed game and opens it.
- Add your own games from the UI, or edit `games.js`.

Plain HTML/CSS/JS, no build step. State is stored in your browser's localStorage.
